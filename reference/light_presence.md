# Presence and absence of COG 4251 with function Bacteriophytochrome (light-regulated signal transduction histidine kinase) within a set of *Prochlorococcus* genomes

Presence and absence of COG 4251 with function Bacteriophytochrome
(light-regulated signal transduction histidine kinase) within a set of
*Prochlorococcus* genomes

## Usage

``` r
light_presence
```

## Format

A data frame object with 31 observations of 5 covariates.

- sample:

  Sample id

- cog:

  COG, all observations are from COG 4251

- presence:

  1 if COG 4251 is present in the sample, 0 otherwise

- clade:

  light level, combined with category I or II

- light:

  HL for high light condition, LL for low light condition
